Glidex

A control plane for KVM virtual machines on Cloud Hypervisor or QEMU, with a web UI, the gxctl CLI and REST and RPC APIs. On one Linux host, or many hosts joined into a cluster.

Quick start Documentation GitHub 
git clone https://github.com/CMKL-APEX/glidex.git && cd glidex
cargo run -p glidex-install

Features

Two hypervisors

Cloud Hypervisor and QEMU boot cloud images through UEFI, with networks, disks, PCI passthrough, pause and graceful shutdown.

Images and disks

Checksum-verified cloud images from a built-in catalog; thin root disks grown with their root partition.

Networking

NAT, isolated and bridged networks on Open vSwitch; kernel, AF_XDP or DPDK uplinks.

Console

Each VM's serial console in the browser or gxctl, shared by any number of clients.

Projects and access

Projects with quotas and roles, PAM and OIDC logins, API tokens, Cedar policies and an audit log.

Clusters

Raft-replicated servers, agents that run VMs, a scheduler, and cluster networks on OVN.
