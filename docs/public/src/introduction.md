# Introduction

Glidex is a control plane for KVM virtual machines on Cloud Hypervisor
or QEMU, with a REST and RPC API, a web UI and a CLI (`gxctl`). It runs
on a single host or as a cluster of hosts.

This documentation is for people who install, use and operate Glidex:

- [Quick start](quick-start.md): install Glidex on one host and boot a VM.
- [User guide](user-guide/README.md): working with VMs, disks, networks
  and projects.
- [Operator guide](operator-guide/README.md): installing, configuring,
  securing and running hosts and clusters.
- [API reference](api/README.md): the public REST and RPC APIs.
